# Public Examples

Public examples are useful only as outcome references.

## BeanLedger

BeanLedger is a public example of the kind of polished App Store listing this skill is meant to help produce:

https://apps.apple.com/app/beanledger/id6739036460

Use it only to discuss visible outcomes such as:

- polished localized screenshot presentation
- consistent visual treatment across store assets
- the level of finish expected from a proof-first pipeline

Do not treat the BeanLedger listing as an implementation dependency.

This skill should not rely on or reference any BeanLedger local files, scripts, launch flags, simulator setup, or internal project structure.
